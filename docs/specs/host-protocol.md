# depth3d Host ⇄ 头显 约定（v1）

## 发现
Host 在局域网用 mDNS 广播 `_depth3d-host._tcp`，端口为 Host 控制接口的 HTTPS 端口。TXT 记录：

| 键 | 值 |
|---|---|
| `v` | `1` |
| `name` | 显示给用户的电脑名 |
| `id` | 稳定的主机 id（首次启动生成的 UUID） |
| `pair` | `auto`（支持免 PIN 配对） |
| `media` | 媒体服务（WebDAV）端口；没开启时不带这个键 |
| `mrev` | 媒体凭据版本号（从 `1` 开始递增的十进制整数）；每次移除已配对设备并轮换 WebDAV 凭据时加 1。媒体服务未开启或尚未轮换过时可省略；已配对头显监听到 `mrev` 变化（或访问 WebDAV 收到 `401`）时，重新调用 `GET /depth3d/v1/media` 拉取最新凭据 |
| `gs` | 内置串流服务的 GameStream HTTP 端口（默认 47989）；串流引擎未就绪（端口冲突、暂停、异常）时不带这个键 |

内置串流服务仍按标准方式（`_nvstream._tcp`）被发现，头显用地址 + `gs` 端口把两条记录合并成一台电脑。Host 不向局域网广播 `_webdav._tcp`；已配对头显统一通过 `/depth3d/v1/media` 获取媒体服务端口与凭据。

## 控制接口
HTTPS，自签名证书；头显首次连接时记住证书指纹（TOFU），之后指纹变了要提示用户。服务端启用可选 TLS 客户端认证（允许无客户端证书访问 `/info` 与首次 `/pair`，并验证头显在 `/pair` 二次连接与 `/media` 时出示的客户端证书及其私钥握手签名 `CertificateVerify`）。

- `GET /depth3d/v1/info` → `{"v":1,"name":"…","id":"…","os":"macOS 15.1","stream":{"ready":true,"reason":null},"media":{"port":8890}|null}`。`stream.ready=false` 时 `reason` 是给用户看的中文短句（如「还没有允许屏幕录制」）。
- `POST /depth3d/v1/pair`，请求体 `{"device":"<头显名>","deviceId":"<头显稳定 id>","pin":"1234"}`。
  - **并发时序与结果确定性**：头显应与 `POST /depth3d/v1/pair` 并发（或先发起）标准 GameStream `/pair` 流程（确保内置引擎已收到来自同一来源 IP 的待配对会话）。Host 在用户确认（或免确认放行）后，把 PIN 仅提交给匹配该请求方 IP 的唯一引擎配对会话，**等待 GameStream 配对真正完成且客户端证书指纹写入并绑定落盘后**，才返回 `200 {"ok":true}`；若引擎未就绪、配对失败、超时或证书绑定失败，返回 `503` 且不保存设备记录。因此头显收到 `200` 后即可立即安全调用 `GET /depth3d/v1/media`。
  - **首次配对（无客户端证书）**：Host 在电脑上弹出不抢焦点的确认窗（显示请求方 IP，默认不勾选「以后自动允许」），关闭弹窗等同于拒绝（返回 `403`），60 s 无人操作返回 `408`。同一时间只显示一个确认窗，并发请求返回 `429`；被拒绝或超时后按**来源 IP**（不按 `deviceId`，防止局域网冒用锁定真设备）施加冷却，冷却期内返回 `429`。
  - **之后的免确认（「以后自动允许」）**：头显发起 `POST /depth3d/v1/pair` 时**必须携带配对时交换的 TLS 客户端证书**。Host 仅在 `deviceId` 存在、勾了「以后自动允许」且 TLS 客户端证书 SHA-256 指纹与绑定记录完全一致时直接放行。
  - **设备身份变化处理**：若请求中的 `deviceId` 在 Host 上已有绑定的证书指纹，但本次未携带客户端证书或证书指纹不一致，Host 一律将其当作新设备处理：弹窗明确警示「这台设备的身份变了」，且即使确认允许也**绝不继承**之前的「以后自动允许」状态。
- `GET /depth3d/v1/media` → `{"webdav":{"port":8890,"user":"…","pass":"…"}}`，只对已完成配对且绑定了客户端证书的 `deviceId` 返回（请求头 `X-Depth3d-Device: <deviceId>`，且 TLS 客户端证书指纹必须与该设备配对时绑定的证书一致并仍在引擎已配对且启用列表中）；否则 `401`。当 Host 移除任一已配对设备时，会立即轮换 WebDAV 凭据并递增 `_depth3d-host._tcp` 的 `mrev` TXT；其余仍配对的头显在收到 WebDAV `401` 或 `mrev` 变更通知后重新调用 `GET /depth3d/v1/media` 获取新凭据。

版本不兼容时返回 `426`，头显提示「请更新电脑上的 depth3d Host」。
