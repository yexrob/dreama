3D：强度、片源、漂浮感、层次

漂浮感和层次放在 3D 页，因为它们本身就是纵深，而且和「强度」联动：强度越高，画面凸得越多，「自动」漂浮感跟着往前。另一个原因：弹幕和字幕共用漂浮感，没有弹幕的片源也要能调字幕的深度。

强度关闭 / 柔和 / 标准 / 强烈 · 只改这部片子
片源自动 / 左右 / 上下 · 只改这部片子
漂浮感「自动」开：跟着画面最靠前的内容，再 −2…+6 格（每格 0.05°）
「自动」关：固定 0–0.60°，显示成当前距离下的厘米数，0 = 贴屏
层次关 0 / 浅 0.15° / 中 0.30° / 深 0.45° · 弹幕分三层的总跨度

怎么改值

射线停在一行上（这一行提亮，数值两边出现 ‹ ›），推右手摇杆左右：一格一振（5 ms / 0.2），经过有名字的档位重振一下（15 ms / 0.5）并停 300 ms，到头连振两下。按住 400 ms 后每秒 8 格。按下摇杆 = 复位这一行。滑杆照样可以拖，作为后备。

存在哪里

强度、片源、字幕轨、音轨跟着片子存，复位回到设置里的默认值；其余（屏幕、漂浮感、弹幕外观…）是一份全局值，和设置页是同一个值，复位回到出厂值。第一次在一部片子里改强度时出一条提示「只改这部片子」。

默认值为什么这样取

字号 1.4°头显每度只有约 18 个像素：静止文字最小 1.1°，移动的字看起来更糊，加 25%；比字幕（1.6°）小一档，字幕仍是主角
半屏50° 画面的上半屏有 7 条轨道，够热闹的片子用；1/4 只剩 3 条，而且在平视以上 7–14°，比自然视线（俯 10–15°）高出 20° 多，要抬头看；全屏会盖住下半部的人物和字幕
8 s 横穿50° 画面上约 7.5°/s，眼睛跟得上还能读完；巨幕时按时间会太快，所以角速度封顶 12°/s
不透明 80%大画面很亮，满不透明的白字太抢；有描边，80% 在亮背景上仍读得清
适中 40 条半屏 7 条轨道、每条约 4 条可见 ≈ 28 条，40 留出顶部 / 底部和全屏的余量

为什么不晕

1. 每条弹幕从出现到离开深度不变：眼睛横着追字时不用改聚散。
2. 按轨道分层，同一行永远同一层；轨道按 远 中 近 中 循环，相邻两行只差 Δ/2（默认 0.15°）。
3. 总范围在 1° 以内，最近不近于 1.6 m，永远在控制条后面。
4. 自动模式下整叠弹幕在画面最靠前的内容之前，不会出现「被挡住的字反而更近」。
5. 两侧 1.5° 羽化，减少浮在前面的字被画面边框切断（窗口冲突）。
6. 深度只靠视差：不做近大远小、近快远慢、近亮远暗。
7. 只有自己拖滑杆时，屏幕上已有的弹幕才一起移到新深度（200 ms）。

怎么算

远层 φ = 内容 + 0.10° + k × 0.05°
（自动；k = −2…+6，默认 0）
远层 φ = k × 0.05°
（固定；k = 0…12，0 = 贴屏）
中层 = 远层 + Δ/2，近层 = 远层 + Δ

「内容」= 深度图在显示区域里的第 98 百分位视差：往前立刻跟，往后每秒最多退 0.05°。3D 关闭时为 0；原生 3D 片源没有深度图，按 0.25°。近层超过上限时先压缩 Δ，再压远层。
