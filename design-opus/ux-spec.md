# depth3d 头显界面规范（design-opus）

适用设备：PICO 4（XR2 Gen 1，单眼 2160×2160，水平视场约 105°），也要能在 Quest 系列上跑。
两个界面面：

- **2D 面板**：一个 Compose Activity，用射线加扳机或捏合操作，基本不打字。
- **VR 场景内界面**：播放时的 OpenXR quad 图层，每帧最多 16 层。

配套设计稿在 `mockups/`，打开 `mockups/index.html` 看总览。每页底部能切换状态，右下角的注释写着这个状态为什么这样做。本文是完整的理由和数值。

文中的 **px** 有两种用法。2D 面板里指 1280×720 设计画布上的像素；VR 播放页里，1° = 20 px，只是作图比例。凡是用来做决定的数，都换算成**视角（°）**。

---

## 0 原则

1. **画面是主角，界面退后。** 背景图和视频占满，界面用深色半透明底。整页最多一个白色主按钮，强调色只用在进度和「已开启」上。参照的是 Apple TV app 和 Infuse 的克制：没有渐变按钮、霓虹描边或玻璃拟态。
2. **按视角定尺寸，不按像素定。** 字号、目标和线宽先从头显的角分辨率推出来，再落到 px（见 §1）。
3. **正常不出声，出问题才说话。** 连得上的播放源不标「已连接」，只有连不上的那一行变红，并给一个动作。
4. **能不打字就不打字。** 依次靠自动发现、扫码在手机上填、Jellyfin 快速连接码、数字 PIN，系统键盘放在最后（§4.6）。
5. **射线经过时界面不乱动。** 悬停只做放大和提亮，不切换内容、不展开、不自动滚动。要改变内容必须点一下。
6. **播放时图层要省。** 一个控件不单独占一层，整条控制条只用一张贴图，调色板也只用一张。任何状态最多 13 层，留 3 层余量（§6.5）。

## 1 尺寸推导

### 1.1 头显能分辨多细

| 量 | 值 | 来源或理由 |
|---|---|---|
| 单眼分辨率 | 2160 × 2160 | PICO 4 规格 |
| 水平视场 | ≈ 105° | PICO 4 规格 |
| 名义角分辨率 | 2160 / 105 ≈ **20.6 PPD** | 平均值，镜片中心略高、边缘更低 |
| 设计用有效 PPD | **18 PPD** | 合成器对 quad 层重采样、镜片边缘衰减、头部微动造成的模糊都会损失清晰度，所以按 ~85% 打折 |

结论：**1° 约等于 18 个可分辨的屏幕像素**。设计稿里任何小于约 1.5 个屏幕像素的东西都会闪烁或消失。

### 1.2 2D 面板

- **假设**：面板显示为 1.6 m 宽，距离眼睛 1.6 m，即 2·atan(0.8/1.6) ≈ **53.1°**。设计画布是 1280×720，所以 **1° ≈ 24.1 px**。
- 一个设计 px 约等于 18 / 24 = **0.75 个屏幕像素**，比手机密得多。由此：
  - **线宽至少 2 px**（0.083°，约 1.5 个屏幕像素）。1 px 的分隔线会抖动，所以本设计不用分隔线，改用间距和底色区分层级。
  - 图标描边 2.2 px（28 px 图标），不用 1.5 px 以下的细线图标。
- 面板的实际物理尺寸由 PICO 系统决定，见 §8。数值不对时整套 token 按比例缩放，比例关系不变。

### 1.3 字号

汉字笔画密，要可靠分辨「赢」「餐」这类字，字高至少需要约 16–18 个屏幕像素。按 18 PPD 计算，**1.0° 是下限**。

| 角色 | px | 视角 | 屏幕像素 | 字重 | 行高 |
|---|---|---|---|---|---|
| display（片名） | 64 | 2.7° | 48 | 600 | 1.1 |
| title（页标题） | 44 | 1.8° | 33 | 600 | 1.2 |
| head（区块标题、弹层标题） | 32 | 1.33° | 24 | 600 | 1.3 |
| body（正文、列表主文字） | 28 | 1.17° | 21 | 400 / 500 | 1.5 |
| caption（次要信息、元数据） | **24** | **1.0°** | 18 | 500 | 1.4 |

- 不用 300 及以下的字重：细笔画在低 PPD 下会断。caption 用 500 补偿。
- 不用负字距。数字统一用等宽数字（`tabular-nums`），这样时间跳动时不会左右抖。
- 一行最多约 28 个汉字（正文 28 px × 28 ≈ 784 px ≈ 33°）。超过这个宽度眼睛要转头去找行首。

### 1.4 目标尺寸

射线的抖动来源有三个：

- 手柄射线静止时的抖动，约 0.3–0.6°。
- 手势射线更大，约 1°。
- 捏合瞬间手指带着射线往下漂，约 1–2°。

| 角色 | px | 视角 | 理由 |
|---|---|---|---|
| 最小目标（次要按钮、分段选项） | **60** | 2.5° | 抖动 ±1° 时仍有 0.25° 余量 |
| 主要目标（主按钮、圆形图标按钮） | **64** | 2.7° | |
| 列表行 | 88 高，整行可点 | 3.65° | 行内只放一个主要动作 |
| 目标之间的空隙 | **≥ 16** | 0.67° | 加上 §4.2 的悬停滞回，防止在边界来回跳 |

### 1.5 对比度

在面板底色 `#0E0F12` 上：

| 前景 | 对比度 | 用途 |
|---|---|---|
| text `#ECECEE` | 16.2 : 1 | 主文字 |
| text-2 `#A6A9B0` | 8.1 : 1 | 次要文字（在 surface-hi 上仍有 6.7 : 1） |
| text-3 `#7D818A` | 4.9 : 1 | **只用于禁用态** |
| accent `#E3A857` | 9.1 : 1 | 进度、已开启 |
| danger `#EE8577` | 7.5 : 1 | 连不上、出错 |

- 次要文字定在 ≥ 7 : 1，比 WCAG AA 的 4.5 高。头显里的对比度会被镜片眩光和合成器模糊吃掉一截，要留余量。
- 纯白 `#FFF` 只在悬停的主按钮上出现。常态主文字用 `#ECECEE`，避免大面积纯白在 OLED 风格的黑底上产生光晕。

### 1.6 VR 场景内

| 量 | 值 | 理由 |
|---|---|---|
| 作图比例 | 1° = 20 px | 只是画图用 |
| 贴图密度 | **40 texel/°** | 约为有效 PPD 的 2 倍，配合 mipmap，头动时文字不闪。再高只是浪费显存和带宽 |
| 最小字 | 22 px = **1.1°** | 比面板的 1.0° 高一点，因为控制条在视线下方 15–21°，那里镜片更糊 |
| 最小目标 | 50 px = **2.5°** | 和面板一致 |
| 播放键 | 64 px = **3.2°** | 播放中最常点的东西 |
| 进度条 | 视觉 0.3° 粗，悬停 0.5°；命中区 **2.5° 高** | 细线好看，命中区要宽 |
| 控制条 | 40° × 5.6°，贴图 1600 × 224 | 只有一张贴图 |
| 调色板 | 20 × 15 cm，贴图 1024 × 768（51.2 texel/cm）；挂在手上时距眼 35–55 cm，约 25° × 19° | 离眼近，所以按厘米定；常用的 45 cm 处 ≈ 40 texel/°（§6.3） |
| 弹幕 | 字号 1.4°（小 1.2° / 大 1.7°），轨道间距 1.82° | 会动的字比静止的糊，在 1.1° 上加 25%（§6.10） |
| 静态字幕 | 字号 1.6°（1.3–2.0°），贴图 1440 × 400 | §6.11 |

### 1.7 到头显上必须核对的

面板的真实物理尺寸和 dp 密度、合成器对 quad 层的实际锐度、手势射线的实际抖动，全部列在 §8。

## 2 信息架构与导航

### 2.1 结构

```
顶部导航（常驻）：首页 · 媒体库 · 投屏                         搜索  设置
│
├─ 首页          继续观看 → 每个播放源一行（最近添加 / 电影 / 剧集…）
│   └─ 详情页（电影 / 剧集）→ 播放（VR）
├─ 媒体库        左：所有播放源   右：选中源的分类
│   ├─ 分类网格 → 详情页 → 播放
│   └─ 管理播放源（播放源与插件）→ 添加播放源 → 用手机输入
├─ 投屏          等待投屏（设备名）+ 电脑串流（Mac / PC）
│   └─ 电脑配对（PIN）
├─ 搜索          （跨所有播放源）
└─ 设置          左栏分类，右栏选项
```

- **只有 3 个一级标签。** 头显里每多一个标签，射线就要多扫一段。设置和搜索是工具，不是目的地，所以放在右上角，做成图标。
- **最深 3 层**（标签 → 列表 → 详情）。推入的页面左上角有圆形返回键，手柄 B 键或系统返回手势也能返回。不做面包屑。
- 标签切换不加横向滑动动画，直接淡入淡出（§5.6）。大面积横移会让人产生自身在动的错觉（vection）。

### 2.2 投屏和串流放在哪里

| 能力 | 方向 | 入口 | 理由 |
|---|---|---|---|
| AirPlay 镜像、DLNA 投送 | 别的设备推过来 | 「投屏」标签只负责**显示设备名并等待**；接收服务只要 App 开着就在后台运行 | 用户真正的操作在 iPad 或手机上，头显这边只需要让对方找得到这个名字 |
| 投屏请求 | 推过来 | 在**任何页面**弹出确认（2D 面板用弹层，播放中用卡片） | 不能要求用户先切到「投屏」页才能接收 |
| Moonlight 串流（Mac / PC） | 头显主动去连 | 「投屏」页下半部分的「电脑串流」 | 和投屏一样，都是「看另一台设备的画面」，用户心里归为一类 |
| depth3d Host（Mac） | 两种角色 | 在「媒体库」里是一个**播放源**（片库，以及经 Mac 的 rclone WebDAV 访问 Google Drive）；在「投屏 › 电脑串流」里是一台**电脑** | 只配对一次，两处都能用。用户不需要理解 Host 是什么，只要知道「装了它，Mac 上的片子和屏幕都能看」 |

### 2.3 首次使用

首次使用有三步（欢迎 → 片源 → 操作），可以跳过。「片源」一步选了 Mac，才多出一步「装 Host」。只想投屏的人什么都不用选，直接继续。

## 3 页面

每页的布局以 `mockups/*.html` 为准，这里只写**规则**和**状态**。共有规则：页面左右边距 64 px；区块标题 32 px；海报行横向滚动，行首和页边距对齐。

### 3.1 首页播放墙（home.html）

| 状态 | 规则 |
|---|---|
| 默认 | 第一屏：上次看的片子做主角（背景图加左侧和底部的遮罩），一个白色「继续播放」加一个「详情」。下面一行「继续观看」，卡片 16:9、264 px 宽，进度条 6 px 高，用强调色。悬停：卡片放大 6%，中间出现播放符号，**点卡片直接续播**，不进详情 |
| 向下滚动 | 英雄区收起，导航从透明改成实底。每个播放源一行海报（168×252），行标题带「›」，可点，进入该分类 |
| 没有播放源 | 标题「还没有可以看的片子」，下面三张卡：局域网里已经发现的服务器（排第一，点一下就加）、头显里的视频、投屏（不用设置）。底部一个文字按钮引导装 Mac Host |
| 加载中 | **超过 300 ms 才出骨架。** 骨架和真实布局同尺寸，只做 1.6 s 的明暗呼吸，不做横扫高光（大面积移动的高光在头显里很晃眼） |
| 一个源连不上 | 只有那一行说话：显示缓存内容并压暗，行标题旁加红色的「连不上 NAS，下面是 2 小时前的内容」和「重试」。其他行照常 |

### 3.2 媒体库（library.html）

| 状态 | 规则 |
|---|---|
| 播放源与分类 | 左栏 392 px 列出所有播放源（图标、名称、一行说明），右栏是选中源的分类方块（3 列）。**悬停不切换右栏，必须点一下**，免得射线扫过左栏时右边跟着乱跳。左栏底部是「管理播放源」 |
| 分类网格 | 6 列海报（172×258），海报上本身印着片名，网格下面不再重复写。右上角只有一个排序按钮（最近添加 / 名称 / 年份） |
| 源连不上 | 右栏换成：红色图标、「连不上『旧电脑共享』」、可能的原因、上次连上的时间、「重试」（主按钮）和「检查设置」。不显示错误代码，代码记在日志里 |

### 3.3 电影详情（movie.html）

| 状态 | 规则 |
|---|---|
| 默认 | 背景图是主角，界面退后。片名 64 px，元数据一行，简介**最多一行**（头显里不读长文），「继续播放」（白）、「从头播放」、收藏。下面是进度条和「剩余 38 分钟」。底部四个设置块：3D / 字幕 / 音轨 / 版本，字小一级、底色更浅，属于第二层 |
| 3D 设置 | 点「3D」弹出：片源三选一（自动转换 / 原片是左右 3D / 原片是上下 3D），强度四档（关闭 / 柔和 / 标准 / 强烈，「关闭」就是看原始 2D）。改了立即生效，**记在这部片子上**，默认值在设置里。点弹层外面或按返回键关闭 |
| 加载中 | 文字先到（来自列表缓存），背景图后到，淡入 240 ms。点播放后按钮在原地转圈、文字变成「正在准备」，不跳页 |
| 不能播放 | 错误留在原地：主按钮下面一行红字「NAS 没有响应，暂时不能播放」加「重试」。不弹窗，不把用户推到别的页面 |

### 3.4 剧集详情（series.html）

| 状态 | 规则 |
|---|---|
| 默认 | 主按钮直接写会播哪一集：「继续播放 · 第 2 季第 4 集」。选季和导航用同一种标签样式。集卡片：看完的只写「已看完」，看到一半的才有进度条。集列表进页时自动滚到「下一集」，左边留一集已看的作为上下文 |
| 切换季 | 标签立即变，集列表换成同尺寸的骨架，页面其他部分不动 |

### 3.5 播放源与插件（sources.html）

| 状态 | 规则 |
|---|---|
| 播放源 | 列表行 88 px，整行可点，点进去能改地址、账号和在首页的顺序。正常的源不写状态，连不上的写红字 |
| 插件 | 每个插件写明**版本、来源（内置或哪个仓库）、能访问什么**（局域网或哪个域名）。有更新时行尾出一个按钮，平时只有箭头。右上角「添加插件仓库」通过手机输入地址 |
| 添加播放源 | 上半部分是**局域网里找到的**（Bonjour、SSDP、Jellyfin 的 UDP 7359 广播），已经加过的写「已添加」。下半部分是手动类型：本机文件夹 / Jellyfin / Emby / WebDAV / SMB / depth3d Host |
| 用手机输入 | 需要填地址或账号时，**不弹头显键盘**，弹出二维码：手机扫码打开一个局域网网页，填完后头显自动继续。不能扫码时，显示地址和 4 位验证码，手动在手机浏览器里输入。Jellyfin 还可以「改用快速连接码」，在已登录的设备上确认 |

### 3.6 投屏（cast.html）

| 状态 | 规则 |
|---|---|
| 等待投屏 | 这页的主角是**设备名**「客厅的 depth3d」（64 px），因为别的设备上要找的就是这几个字。iPad / iPhone 和手机视频 App 的做法各写一句。下面是「电脑串流」：已配对的 Mac、未配对的 PC、添加电脑 |
| 首次确认 | 陌生设备第一次投屏时，弹层「小林的 iPhone 想投屏到这里」，加一个开关「以后自动允许这台设备」（默认开），按钮「允许」（白）和「拒绝」。**在任何页面都会弹出** |
| 连接中 | 居中：转圈、「正在连接小林的 iPad」、「画面一出来就会自动进入 3D 播放」、「取消」。连上后直接进 VR 播放，不需要再点 |
| 电脑配对 | Sunshine 需要 PIN：数字放到 88 px、字距加宽，方便对着抄。装了 depth3d Host 的 Mac 自动配对，不需要这一步 |
| 没有网络 | 居中：红色 Wi-Fi 图标、「还没连上 Wi-Fi」、一句原因，只给一个动作「打开 Wi-Fi 设置」 |

### 3.7 首次使用引导（onboarding.html）

| 步骤 | 规则 |
|---|---|
| 1 欢迎 | 只有名字、一句话、一个按钮。插图用三层错开的画面暗示「深度」，不放产品截图 |
| 2 片源 | 三个可多选的大卡片（368×232）。局域网里已经发现的服务器**预先勾上**。「只想投屏？直接继续，不需要设置」 |
| 2b 装 Host | 选了 Mac 才出现。地址短到可以照着敲（`depth3d.app/mac`，域名待定，见 §8），三步说明，底部「正在局域网里找 Mac…」。装好后头显自动发现 |
| 3 操作 | 只教三件事：扳机或捏合、摇杆左右、按住握把。教完就开始看片，其他操作在播放时随用随现 |

### 3.8 设置（settings.html）

左栏分类：播放与 3D / 屏幕与环境 / 弹幕与字幕 / 投屏 / 手柄与手势 / 播放源 / 隐私 / 关于。右栏是选项。

- 每行 88 px，整行可点。**选项少于 5 个时直接平铺成分段选择**，不用下拉，因为下拉在头显里要点两次，还会遮住别的行。
- 值分两类（§6.3「存在哪里」）：
  - **跟着片子存**：3D 强度、片源格式、字幕轨、音轨。设置里改的是新片子的默认值，播放中在调色板里改的只影响这部片子。
  - **全局值**：其余所有项，设置页和调色板改的是**同一个值**。
- 「播放与 3D」：默认 3D 强度、识别原生 3D 片源、深度计算（流畅优先 / 画质优先）、漂浮感（自动 +0）、层次（中）、片尾自动播下一集。
- 「屏幕与环境」：
  - 屏幕大小 30–90°，档位小 40° / **中 50°** / 大 62° / 巨幕 80°；
  - 距离 2–8 m，档位 2 / **3** / 5 m；
  - 曲度 0–100%（出厂 **0%**，即平面；原来的「曲面屏幕」开关并进这个滑杆）；
  - 播放时调暗房间、默认环境。
- 「弹幕与字幕」（新）：

  | 项 | 出厂值 | 理由在 |
  |---|---|---|
  | 弹幕 | 开（片源有弹幕时） | |
  | 区域 | 全屏 / **半屏** / 1/4 | §6.10 |
  | 不透明 | **80%**（20–100%） | §6.10 |

## 4 VR 交互规则（2D 面板和场景内通用）

### 4.1 指向方式

| 输入 | 指 | 选 | 滚动 |
|---|---|---|---|
| 手柄 | 射线 | 扳机（按下再在同一目标上松开） | 摇杆，或者按住扳机拖 |
| 手势 | 手势射线 | 捏合（同上） | 捏住拖动 |

- 点击 = **在同一个目标上按下再松开**。按下后移出目标再松开就算取消，给用户反悔的机会。
- 不用长按：射线状态下长按很难稳住。次要动作都做成看得见的按钮。
- 唯一的例外是在画面上**按住扳机再推摇杆**，用来调整屏幕（§6.12）。单独按住不推什么都不做，所以仍然没有「长按就触发」的动作。

### 4.2 悬停与焦点

- 射线进入目标：120 ms 内放大（按钮 1.04，海报和卡片 1.06），底色升一级（`fill` → `fill-hi`）。文字颜色不变。
- **滞回**：射线进入目标的命中框就算悬停；离开时要超出命中框外扩的 8 px（0.33°）才算离开，防止射线压在边界上时闪烁。放大 1.04 后，视觉上也正好覆盖了这一圈。
- 同时只有一个目标处于悬停。没有「键盘焦点环」：头显里没有 Tab 键，焦点就是射线所指。
- 悬停**不改变布局**：不展开、不切换内容、不出提示气泡（进度条的时间气泡是唯一例外，它浮在上方，不占位置）。
- 射线所指的点是一个 18 px 的白点，外加一圈 3 px 的深色描边，在亮的画面和暗的界面上都看得见。

### 4.3 捏合冻结

捏合的那一下，手指会带着射线往下漂 1–2°。规则：

1. 选中判定用**捏合开始前约 80 ms 的射线位置**，而不是捏合那一刻的位置。
2. 捏住期间射线移动不超过 1.5° 时，算一次点击，射线视觉上冻结在原位。
3. 超过 1.5° 就转成拖动或滚动，不再算点击。

80 ms 和 1.5° 都是初始值，要在头显上实测（§8）。

### 4.4 滚动

- 海报行横向滚动，页面纵向滚动。可以用摇杆（每推一下移动一屏的 80%），也可以按住拖（有惯性，最后吸附到卡片边缘）。
- **不做射线停在边缘自动滚动**：在头显里，内容自己移动会让人头晕，也容易误触。
- 滚动时暂停悬停效果，停下 150 ms 后再恢复，免得卡片一路扫过一路放大。

### 4.5 触觉与声音

- 手柄振动：
  - 悬停进入时轻触（约 5 ms，强度 0.2）。
  - 点击约 15 ms、强度 0.5。

- 调色板和调整屏幕时改值的振动：

  | 事件 | 振动 |
  |---|---|
  | 走一格 | 5 ms / 0.2 |
  | 经过有名字的档位（比如「中 50°」「3 m」「标准」） | 15 ms / 0.5，并在档位上停 300 ms |
  | 到头 | 连振两下（10 ms / 0.4，间隔 60 ms） |
  | 按住摇杆连续改值 | 400 ms 后开始，每秒 8 格，每格照样振 |

- 调整屏幕时按住 350 ms 还没推摇杆：出提示，同时轻振一下（5 ms / 0.2）。
- 手势输入没有触觉。档位靠视觉表示：在档位上同样停 300 ms，对应的刻度线提亮。
- 不加界面音效。看片的 App 应该安静。

### 4.6 不用键盘的输入顺序

| 优先级 | 方式 | 用在哪 |
|---|---|---|
| 1 | **自动发现**：Bonjour（mDNS）、SSDP / DLNA、Jellyfin 的 UDP 7359 广播 | 添加播放源、找 Mac Host、首次使用 |
| 2 | **手机扫码**：头显开一个局域网网页（显示地址和 4 位验证码），用手机填 | 服务器地址、账号密码、插件仓库地址 |
| 3 | **Jellyfin 快速连接码**：头显显示 6 位码，在已登录的设备上确认 | Jellyfin 登录 |
| 4 | **数字 PIN**：只有 4 个数字，用数字按钮输入 | Sunshine 配对（头显显示，电脑上输入） |
| 5 | 系统键盘 | 搜索，以及上面都不行的时候 |

## 5 视觉规范

### 5.1 颜色

| token | 值 | 用途 |
|---|---|---|
| `bg` | `#0E0F12` | 面板底色（不用纯黑，纯黑在 LCD 上发灰，还会和房间的透视画面形成刺眼的边缘） |
| `surface` | `#17191D` | 卡片、列表行、骨架 |
| `surface-hi` | `#202328` | 悬停的行 |
| `sheet` | `#1A1C20` | 弹层 |
| `fill` / `fill-hi` | 白 10% / 18% | 次要按钮、悬停 |
| `sel` | 白 20% | 选中的标签和分段 |
| `text` / `text-2` / `text-3` | `#ECECEE` / `#A6A9B0` / `#7D818A` | 主文字 / 次要文字 / 只用于禁用 |
| `accent` | `#E3A857`（琥珀） | **只用于**进度条和「已开启」的开关 |
| `danger` | `#EE8577` | 连不上、出错 |
| 遮罩 | `#08090B` 66% | 弹层背后 |

- 选琥珀不选蓝：蓝色在暗场里像系统控件，在电影画面上很跳；琥珀接近放映厅的暖光，在冷调和暖调的画面上都不突兀。
- **渐变只用作图片上的遮罩**（让文字压得住背景图），不用在按钮或底色上。
- **每屏最多一个白色主按钮**，这样一眼就知道该点哪里。

### 5.2 字号

见 §1.3。中文字体用系统的 Noto Sans CJK / 思源黑体，西文和数字用同一字体，不混排第二种西文字体。

### 5.3 间距

- 8 px 网格。页面左右边距 64 px（2.7°）。
- 区块之间 40–56 px，同一区块内 16–24 px，卡片之间 24 px。
- 海报行的行高要能容下放大 1.06 后的卡片，上下各留 ≥ 16 px，放大时不能被裁切。

### 5.4 圆角

| 元素 | 圆角 |
|---|---|
| 面板、弹层 | 28 px |
| 卡片、按钮、列表行、方块 | 16 px（海报 14 px） |
| 标签、开关、圆形按钮 | 全圆 |
| VR 控制条、弹出卡片 | 24 px（1.2°） |
| 调色板 | 48 texel（0.94 cm） |

### 5.5 阴影与层次

层次靠底色深浅（bg → surface → surface-hi → sheet）区分，不靠阴影。阴影只用在两处：浮起的弹层，以及悬停放大的海报（让它从行里浮出来）。

### 5.6 动效

| 场景 | 时长 | 曲线 | 说明 |
|---|---|---|---|
| 悬停（按钮、行） | 120 ms | `cubic-bezier(.2,.8,.2,1)` | 放大 1.04 + 底色 |
| 悬停（海报、卡片） | 140 ms | 同上 | 放大 1.06 + 阴影 |
| 弹层进入 / 退出 | 200 / 140 ms | 同上 | 淡入 + 上移 16 px |
| 页面推入 / 返回 | 220 ms | 同上 | 交叉淡入 + 24 px 位移，**不做整页横移** |
| 标签切换 | 160 ms | 线性 | 只淡入淡出 |
| 骨架 | 1.6 s 一周 | ease-in-out | 延迟 300 ms 才出现 |
| 背景图 | 240 ms | 线性 | 淡入 |
| VR 控制条出现 / 消失 | 180 / 300 ms | | 淡入 + 上移 0.5° / 淡出 |
| 调暗房间 / 开灯 | 600 / 300 ms | | 开始播放时慢慢变暗，暂停时较快亮回来 |
| 调色板打开 / 收起 | 160 / 120 ms | `cubic-bezier(.2,.8,.2,1)` | 淡入 + 从 0.96 放大到 1 / 淡出 |
| 调色板钉住 / 回到手上 | 200 ms | 同上 | 钉住时就地转正；回到手上时飞回握把上方 |
| 字幕给钉住的调色板或卡片让位 | 200 ms | 同上 | 只上下移动，滞回 1° |
| 弹幕和字幕换深度 | 200 ms | 同上 | 只在自己拖「漂浮感」「层次」时发生（§6.10） |
| 顶部 / 底部弹幕 | 150 ms | 线性 | 淡入淡出 |
| 滚动弹幕 | 匀速 | — | 不加缓动，进出画面靠两侧 1.5° 羽化，不做淡入 |
| 调整屏幕 | 跟手 | — | 没有缓动；经过档位停 300 ms |

禁止：弹跳、视差动画、整个面板移动，以及任何让视野大面积运动的效果。

- 调色板是例外。它只有 20 × 15 cm，而且是自己点的，所以可以移动。
- 弹幕的「分层漂浮」是**双眼视差**：每条弹幕固定在一个深度上。它不是运动视差，不做近快远慢（§6.10）。

## 6 VR 播放中

两份画稿：

- `mockups/vr-player.html`：控制条、弹出卡片、提示。
- `mockups/vr-palette.html`：调色板、弹幕、字幕、调整屏幕和按键判定。

两份画的都是头显视野（80° × 50°），视线中心在 (800, 500)。

### 6.1 布局

| 元素 | 位置与尺寸 | 理由 |
|---|---|---|
| 画面 | 默认「中」宽 **50°**（16:9 时高 28°），中心在视线水平线上，下沿俯角 14°。默认距离 3 m（2.8 m 宽，约 126 英寸），默认平面；大小、距离、曲度见 §6.12 | 50° 是整幅画面不用转头就能看全的上限。大小按角度定，所以改距离只改立体纵深，不改画面看起来多大 |
| 弹幕 | 在画面内。默认上半屏 7 条轨道，字号 1.4°；深度在画面最靠前的内容和控制条之间，分远、中、近三层（§6.10） | 弹幕是看片的一部分，放在画面里；浮在画面前面，读起来不贴着画面 |
| 字幕 | 在画面内，下沿上方 2°（1–12°），字号 1.6°；深度和弹幕的远层相同。被**钉住的调色板**或**弹出卡片**挡住时，抬到它上沿以上 1°（§6.11） | 字幕永远不被界面挡住 |
| 控制条 | **40° × 5.6°**，距眼 **1.4 m**，俯角 15.3°–20.9°，上沿比画面下沿低约 1.3° | 不压在画面上。它比画面和弹幕都近，所以 2D 转 3D 后凸出来的东西不会穿过它（避免立体窗口冲突）。1.4 m 接近手臂能够到的距离，聚焦舒服 |
| 控制条俯角限制 | **10°–30°** | 画面放大到「巨幕」时控制条跟着下沉，但不低于 30°，再低就要低头；画面缩小时不高于 10°，再高就会挡画面 |
| 退出键 | 56 px（2.8°）圆形，在控制条左边，单独浮着 | 和播放键分开，避免误触；进度总会保存，所以离开播放不用确认 |
| 调色板 | 挂在左手握把上方，**20 × 15 cm**，距眼 35–55 cm；可以钉在空中（§6.3） | 低频设置跟着手走：抬手就到眼前，放下就离开视野。不占画面周围的空间 |
| 弹出卡片 | 控制条上方，右缘和控制条右缘对齐（原来快捷菜单的位置） | §6.6 |
| 提示（toast） | 头部锁定但懒跟随，在视线下方 18°，高 2.6°。调整屏幕时的读数也用这个槽位 | 不管看向哪里都看得到。懒跟随是头转动超过 10° 才跟上，带 300 ms 缓动，这样不会像贴在眼镜上一样晃 |

控制条里从左到右是：

- 播放 / 暂停：64 px 白色圆。
- 片名一行：片名用 600 字重，后面的「· 年份 · 来自 NAS」用 text-2。
- 进度条：左边是已播时间，右边是**剩余时间**（带负号）。
- 「弹」：56 px（2.8°）圆钮，在「调整」左边，**只在片源有弹幕时出现**。这时进度条从 27.2° 缩到 23.2°。
  - 开：琥珀色描边加琥珀色字。
  - 关：灰字加斜线。
- 「调整」药丸按钮：打开调色板（§6.3）。

### 6.2 出现与消失

| 条件 | 行为 |
|---|---|
| 射线进入画面或控制条 | 控制条淡入（180 ms） |
| 射线离开画面和控制条 **3 s** 后，或射线一直不动 **4 s** | 淡出（300 ms） |
| 暂停 | 控制条**常驻**，不隐藏；房间亮回来（调暗层从 58% 降到 14%）；弹幕原地停住 |
| 调色板打开 | 不影响控制条：射线指到画面或控制条时，控制条照常出现 |
| 调整屏幕中 | 控制条和提示隐藏，提示槽位只显示读数。调色板开着时，它的层降到 40% 不透明（改层的透明度，不重画） |
| 什么都不碰 | 只剩画面、弹幕和字幕。射线和手柄模型也隐藏，碰一下扳机或动一下摇杆再出现 |

### 6.3 调色板

画稿：`vr-palette.html` 的「3D 页」到「钉住」。

它取代原来的快捷菜单。快捷菜单有三个问题：

- 要先叫出控制条，再点「调整」，至少两步。
- 打开时挡住画面下部和字幕。
- 只有 5 个标签 × 3 行，放不下弹幕。

调色板参照 Open Brush：面板挂在左手上，右手射线操作。

**尺寸**（贴图 px，51.2 texel/cm）

| 量 | 值 | 理由 |
|---|---|---|
| 面板 | **20 × 15 cm**，贴图 **1024 × 768**，圆角 48（0.94 cm） | 在 45 cm 处约 25° × 19°。抬手能看全，又不会挡住整个视野。贴图不超过 1024 × 768 |
| 贴图密度 | 45 cm 处 ≈ 40 texel/°；55 cm 处 49；35 cm 处 31 | 最近时仍有有效 PPD 的 1.7 倍 |
| 标签栏 | 高 128（2.5 cm）：4 个标签加右端的图钉（128 × 128） | |
| 行 | 每页**最多 4 行**，行高 **144 = 2.81 cm**（45 cm 处 3.6°，55 cm 处 2.9°） | 射线从另一只手来，两只手都在抖，行再密就点不准 |
| 一行的分区 | 标签（≤ 3 个字）· 控件区 592 · 复位钮 128 × 128 | 复位钮只在值**不等于默认值**时出现 |
| 最小目标 | **128 = 2.5 cm**（55 cm 处 2.6°） | 按最远的 55 cm 算，仍不小于 §1.4 的 2.5° |
| 目标间隔 | ≥ 24 = 0.47 cm | |
| 字 | 56 = **1.09 cm**（55 cm 处 1.14°，45 cm 处 1.39°）；数值 60 px，600 字重 | 按最远处算，不小于 1.1° |
| 悬停滞回 | 命中框外扩 20（0.39 cm） | 同 §4.2，按厘米换算 |
| 边缘死区 | 面板外 1.5 cm 一圈 | 射线在这一圈里既不算调色板也不算画面，扳机不会「穿过去」暂停 |

**标签与行**

| 标签 | 第 1 行 | 第 2 行 | 第 3 行 | 第 4 行 |
|---|---|---|---|---|
| 3D | 强度：关闭 / 柔和 / 标准 / 强烈 | 片源：自动 / 左右 / 上下 | 漂浮感：「自动」开关 + −2…+6 格（每格 0.05°）；关掉自动时固定 0–0.60° | 层次：关 / 浅 / **中** / 深 |
| 屏幕 | 大小：30–90°，档位 40 / 50 / 62 / 80 | 距离：2–8 m，对数刻度，档位 2 / 3 / 5 | 曲度：0–100%，每格 5% | 环境：透视 / 调暗 / 影院 / 纯黑 |
| 弹幕（第一页） | 弹幕：开 / 关 | 区域：全屏 / **半屏** / 1/4 | 不透明：20–100%，每格 10% | 更多：字号 · 速度 · 屏蔽 › |
| 弹幕（第二页） | 字号：小 / **中** / 大 | 速度：慢 / **标准** / 快 | 屏蔽：滚动 / 顶部 / 底部 / 彩色（多选，划线 = 不显示） | ‹ 返回 |
| 字幕音轨 | 字幕：‹ 简体中文 › | 音轨：‹ 国语 · 5.1 › | 字号：小 / **中** / 大 | 位置：1–12°，每格 0.5° |

这样分的理由：

- **漂浮感和层次放在 3D 页，不放在弹幕页。**
  - 它们本身就是纵深，而且和「强度」联动：强度越高，画面凸得越多，「自动」漂浮感跟着往前。
  - 弹幕和字幕共用漂浮感，没有弹幕的片源也要能调字幕的深度。
- **弹幕分两页。**
  - 第一页放看片中途会改的：开关、区域、不透明度。
  - 第二页放设一次就不动的：字号、速度、屏蔽。
  - 第 4 行固定是翻页入口，「更多」和「返回」在同一个位置。
  - 切到别的标签再回来，回到第一页。
- **原来的「环境」标签并进屏幕页。** 「播放时调暗」从开关变成环境里的一个选项。
- **字幕和音轨合成一页。** 「字幕与音轨」五个字放不进标签栏：56 px 的字，4 个标签加图钉共 1000 px。所以标签写成「字幕音轨」。
- **只在设置里改的项**：
  - 弹幕的密度、合并重复和弹幕曲度；
  - 字幕的背景、字幕曲度和默认字幕语言。
- **去掉了「重新放到正前方」。** 长按 PICO 键就是系统的重新居中，App 跟着把画面放回正前方。头部放不下第三个按钮，也没必要重复。

**操作**（手柄；调色板挂在右手时左右对调）

| 输入 | 动作 |
|---|---|
| 左手 ≡ | 打开 / 收起。钉住时按 ≡ 也是收起 |
| 控制条「调整」 | 在面前打开，钉在视线下方 20°、0.5 m 处。点完按钮后要能马上看到，所以不放到手上（手可能放在腿上） |

- 大小：1°。
- 距离：×1.05，在 2 m 时约 0.1 m，在 8 m 时约 0.4 m。
- 曲度：5%。
- 不透明：10%。
- 漂浮感：0.05°。
- 位置：0.5°。

振动按 §4.5。改了**立即生效**，没有「确定」。

**挂在手上**

画稿：「挂载」。

| 量 | 值 |
|---|---|
| 位置 | 下沿在握把原点上方约 **8 cm**（不压住手柄的环），朝身体中线偏 **2 cm** |
| 角度 | 相对握把后仰约 **40°**；再按眼睛方向修正，最多 **20°**，经过 100 ms 低通，免得手抖时面板跟着抖 |
| 距离 | 自然抬手时 35–55 cm，常用 45 cm |
| 失效 | 面板法线和视线夹角 > **60°**：淡出，射线打不中 |
| 托着它的手 | 射线、扳机、握把都不工作，只有 ≡ 和摇杆 |

这些数都是估计值，要在头显上调（§8）。

**钉住**

画稿：「钉住」。

- 点图钉：调色板留在当前位置，转成竖直、正对头部。右手握把按住可以拖。
- 再点一次图钉，调色板用 200 ms 飞回手上。
- 下次按 ≡ 时：
  - 上次钉住的位置还在视线 ±60° 内，就在原处打开；
  - 否则在手上打开。
- 钉住的调色板挡住字幕时，字幕抬到它上沿以上 1°（滞回 1°，200 ms）。
- 弹幕**不让**，从调色板后面经过。调色板更近，约 0.5 m，层也排在弹幕之后，所以深度和遮挡一致。
- **手上的调色板不推字幕。** 手一直在动，字幕跟着跳比被挡一下更糟。而且看手上的调色板时，画面在视野上沿外面。
- 调弹幕时最好把调色板钉到画面旁边，一边调一边看。屏幕上没有弹幕或在暂停时，打开弹幕页会在显示区域里摆三条静止的「弹幕预览」，每层一条。

**存在哪里**

| 类 | 包括 | 复位回到 |
|---|---|---|
| 跟着片子存 | 强度、片源、字幕轨、音轨 | 设置里的默认值 |
| 全局值 | 其余所有项（屏幕、漂浮感、层次、弹幕外观、字幕外观……） | 出厂值。和设置页是**同一个值** |

第一次在一部片子里改强度时，出一条提示「只改这部片子」。

**不能用时变灰并写原因**

画稿：「特殊情况」。

标签和行不跳位置，只在原位置变灰或换内容。

| 情况 | 怎么显示 |

| 片源不提供弹幕 | 弹幕标签还在，内容写「这个片源不提供弹幕 · 插件声明了弹幕能力才有」。控制条上没有「弹」；按 Y 出提示「这个片源没有弹幕」 |

**手势追踪**

- 调色板总是钉住，从控制条「调整」打开，位置在视线下方 20°、0.5 m。
- 图钉换成 ×。
- 改一行有两种方式：
  - 捏住这一行左右拖，每 8 mm 一格；
  - 捏一下滑杆，直接跳到那里。

**重画**

- 贴图只在内容变化时重画：
  - 悬停的行变了（这一行提亮，数值两边出现 ‹ ›）；
  - 值变了；
  - 换了标签或翻了页。

- 透明度用层的属性改。

**判定规则**

1. **按下扳机那一刻射线指着什么，就决定了这一次按的意思。**
   - 按在控件上（控制条、调色板、卡片、进度条），永远是点或拖那个控件，不会进入调整。
   - 按在画面上，才走下面的 2–6。
2. **单击**：350 ms 内松开，并且摇杆一直在死区（0.25）里，就是播放 / 暂停。
3. **调整**：按住期间，摇杆任何时候过了 0.5，就进入调整，不用等 350 ms。
   - 松开扳机 = 保存。不算单击，也不暂停。
   - 调整开始后，射线指到哪里都无所谓。
4. **按住不推**：超过 350 ms 摇杆还没过 0.5，就出提示「推摇杆：前后调远近 · 左右调大小」并轻振。之后松开什么都不做。
5. **先推后按**：按下扳机时摇杆已经偏着（比如正在快进），快进照常进行到摇杆回中。回中之后再推，才进入调整。
6. **中途离开**：调整开始前射线离开了画面，这次取消。松开什么都不做，也不暂停。
7. **锁轴**：先过阈值的那根轴锁定，摇杆回到死区才能换轴。所以推远近时不会顺手改了大小。
8. **摇杆左右的意思在推出去那一刻定下来，回中之前不变。**
   - 推出去时射线在调色板的一行上，就是改这一行。
   - 射线在其他地方（画面、控制条、空处），就是快进快退。
   - 射线在调色板的标签栏或空白处，什么都不做。
   - 按住摇杆连续改值时，射线滑出这一行，连续改值就停，也不会变成快进。
9. **调色板不是模态的。** 开着时点画面照样播放 / 暂停，快进快退照常。关它要用 ≡、B 或图钉（手势时是 ×）。
10. **B 的顺序**：调整中先撤销；不在调整中时依次关错误、投屏请求、下一集、调色板。都没有时，出「再按一次退出播放」。
11. **摇杆上下在播放时没有动作。** 原来的「摇杆上下改 3D 强度」去掉了：它和调整屏幕的「前后 = 远近」抢同一根轴，在看片时也容易蹭到。强度在调色板 3D 页改。
12. 设置里关掉「按住扳机调整屏幕」后，规则 3–7 只对握把有效。扳机在画面上只剩单击。

**手势对应**

画稿：「特殊情况」里的手势追踪。

| 动作 | 手柄 | 手势 |
|---|---|---|
| 播放 / 暂停 | 扳机点画面，或 A | 捏一下画面 |
| 快进快退 | 摇杆左右 | 拖进度条 |

### 6.5 图层预算

上限 16 层。

- 本设计**全部槽位加起来 14 层**。
- 任何状态**同时最多 13 层**，因为提示 / 读数和控制条不同时出现。

| 控制条 | **1** | 退出键、播放键、片名、进度条、时间、「弹」、调整按钮**全在一张贴图里**。命中测试在贴图坐标里做 |

### 6.6 弹出卡片

全部在控制条上方、右缘对齐（原来快捷菜单的位置），一次只出一个。优先级：错误 > 投屏请求 > 下一集。调色板不再占这个槽位，可以和卡片同时开着（12 层，§6.5）。

| 卡片 | 何时出现 | 内容与行为 |
|---|---|---|
| 下一集 | 片尾字幕开始时（有片尾标记就用标记，没有就在结束前 30 s） | 缩略图、「第 5 集 · 迷雾」、圆环倒数 8 s；「立即播放」（白）和「取消」。倒数结束就播下一集。不遮画面中央 |
| 投屏请求 | 看片时有设备投屏过来 | 「小林的 iPhone 想投屏到这里」、「《雾港》会暂停，并记住看到哪里」；「切换过去」（白）和「忽略」。**看片时不自动切换**，即使是已经自动允许的设备也一样。20 s 不处理就算忽略 |
| 缓冲 | 缓冲**超过 500 ms** 才出现 | 画面中央一个药丸：转圈加「正在缓冲」，不显示百分比。超过 10 s 换成带「重试」的错误卡片 |

### 6.7 提示（toast）

- 用于这些场合：
  - 快进快退的时间；
  - 「再按一次退出播放」；
  - Y 键开关弹幕（「弹幕 已关」）；
  - 「这个片源没有弹幕」；
  - 第一次在一部片子里改强度时的「只改这部片子」。
- 一行字，可以带一个状态指示。
- 调整屏幕时，这个槽位换成读数（§6.12）。读数要等松开才消失，不受 2.5 s 限制。
- 同时只出一个，新的直接**替换**旧的，不堆叠。显示 2.5 s，不接受点击。
- **控制条显示时不出 toast**：那时信息直接体现在控制条上（进度、时间）。

### 6.8 和现在的 TransportBar 有什么不同

参照：`player/.../local/TransportBar.java` 和 `xr_layers.c` 顶部的图层清单（只读，没有修改）。

| 现在 | 这个设计 | 为什么 |
|---|---|---|
| 进度条贴在**画面平面**底部（画面宽度减去两边各 2%，高约画面的 12%） | 独立的 quad，**1.4 m，在画面下方** | 不再挡画面。界面在画面的深度上，会和 2D 转 3D 后凸出来的内容打架（立体窗口冲突）；放到更近处就没有这个问题 |
| 控制条是药丸加 7 个按钮（退出、手柄、环境、设置、键盘、射线、3D），每个按钮一层，单是控制条状态就 14–17 层，要靠丢层压回 16 | 整条控制条 1 层，调色板 1 层。加上弹幕的 2 层，任何状态最多 13 层 | 不需要丢层逻辑；省下来的层给了弹幕 |
| 7 个按钮常驻 | 只留播放、进度、退出、「弹」（有弹幕时）和「调整」。环境、3D、屏幕放进调色板；手柄和键盘只在电脑串流时出现（§6.9） | 看片时最常用的是暂停、拖进度和开关弹幕，其余是偶尔调一次的设置 |
| 进度和悬停色是青色 `#7FD4FF` | 进度用琥珀，悬停用放大加提亮 | 青色像系统控件，在电影画面上跳。悬停不靠变色，色弱用户也能分辨 |
| 悬停进度条时，右边的总时长被换成悬停位置的时间 | 右边**始终是剩余时间**，悬停时间放在进度条上方的气泡里 | 同一个位置的数字不应该变成另一种意思 |
| 片名只在暂停时出现，26 texel（约 0.8°）、60% 白 | 片名常驻，1.1°，text-2（7 : 1 以上） | 低于 1° 的汉字读不清 |
| 进度条 10 texel 粗（约 0.3°），命中区是条高的 ±35% | 视觉 0.3°，悬停 0.5°，**命中区固定 2.5° 高** | 线细好看，命中区宽好点 |

### 6.9 电脑串流时的控制条（只写规则，没有画稿）

- 同一张贴图、同一位置。进度条换成「书房 Mac · 串流中」加延迟和码率（只有出问题时才显示数字，比如延迟 > 60 ms 时变红）。
- 「调整」左边多出「键盘」「手柄」两个按钮，总宽度不变。没有「弹」。
- 调色板的标签变成 3D / 屏幕 / 串流。「串流」页放分辨率、码率和鼠标模式。

### 6.10 弹幕

画稿：`vr-palette.html` 的「弹幕平面」「弹幕曲面」「轨道规则」「漂浮感」「弹幕开关」。

这里的弹幕指 B 站那种：评论按时间点从画面上飘过。它和画面一起看，是这一版的重点。静态字幕降为次要（§6.11）。

**数据**

- 每条弹幕的格式：

  ```
  { timeMs, text, color?, mode: 'scroll' | 'top' | 'bottom' }
  ```

  - 没有 `color` 时用白色 `#FFFFFF`。
  - `mode` 是滚动、顶部或底部。
- 弹幕由插件提供。插件声明了弹幕能力，这个片源才有弹幕。没有弹幕时怎么显示见 §6.3「不能用时变灰并写原因」。
- 按 60 s 一段取，提前 10 s 取下一段。
- 拖进度后丢掉手上的，从新时间点重新取。
- 取失败时，调色板弹幕页显示「弹幕没加载出来」加「重试」，不弹提示打扰看片。

**样式**

| 量 | 值 | 理由 |
|---|---|---|
| 字体 | 思源黑体（Noto Sans CJK SC）Bold 700 | 移动中的细笔画更容易糊 |
| 字号 | 小 1.2° / **中 1.4°** / 大 1.7° | 头显每度约 18 个像素。静止文字最小 1.1°，移动的字看起来更糊，所以加 25%。比字幕（1.6°）小一档，字幕仍是主角 |
| 描边 | 0.08 em `#0E0F12`，再加 1 texel 软阴影，**烘进图集** | 不靠底色，在亮的天空和白墙上也读得清 |
| 不透明 | **80%**（20–100%），渲染时统一乘 | 大画面很亮，满不透明的白字太抢。有描边，80% 在亮背景上仍读得清。改了立刻对屏上所有弹幕生效 |
| 颜色 | 按数据原样显示，不改色 | 颜色是发弹幕的人想表达的；嫌乱就屏蔽「彩色」 |

**轨道**

- 轨道间距 = 字号 × 1.3 = **1.82°**（中号）。
- 轨道数 = （区域高 − 0.5°）÷ 轨道间距。下表按 50° 画面、中号字：

  | 区域 | 范围 | 轨道 |
  |---|---|---|
  | 全屏 | 画面上沿到字幕区上沿。字幕区是画面下沿往上 6.5° | 11 |
  | **半屏**（默认） | 画面上半 | **7** |
  | 1/4 | 画面最上面的 1/4，平视以上 7–14° | 3 |

- 默认半屏的理由：
  - 50° 画面的上半屏有 7 条轨道，够热闹的片子用。
  - 1/4 只剩 3 条，而且在平视以上 7–14°。这比自然视线（俯 10–15°）高出 20° 多，要抬头看。
  - 全屏会盖住下半部的人物和字幕。
- 轨道不高于平视以上 **18°**。巨幕时画面上沿到 +22°，上面那几条不用。
- **滚动弹幕**：
  - 所有滚动弹幕同一个角速度：横穿画面 慢 10 s / **标准 8 s** / 快 6 s。50° 画面上标准速度约 7.5°/s，眼睛跟得上，也读得完。
  - 巨幕时如果按时间算会太快，所以角速度封顶 **12°/s**。
  - 同一个速度意味着后面的追不上前面的，同一条轨道里不会撞。
  - 从上往下找空轨道。一条轨道可以进新弹幕的条件：前一条的尾巴离画面右缘 ≥ 间隔（适中 2 个字）。
  - 所有轨道都满时，新弹幕等待，最多 1 s。还没有空轨道就**丢掉**，不补。
- **顶部 / 底部弹幕**：
  - 居中，停 4 s，在**最近一层**。滚动弹幕从它后面经过。
  - 顶部的从区域上沿往下排。
  - 底部的从字幕上方往上排，最多 3 行。
  - 满了同样最多等 1 s。
- **字幕区**：滚动轨道不进字幕区。底部弹幕排在字幕上面。
- **太长**：最多 40 个字，且不宽于画面的 60%，超出用「…」。换行并成一行。
- **合并重复**（默认开）：5 s 内文字相同的弹幕有 3 条以上，就合成一条「哈哈哈 ×12」。合并在取到的那一批里往后看，出现时就定好，之后不变。
- **密度**：

  | 档 | 同屏最多 | 同轨间隔 |
  |---|---|---|
  | 稀疏 | 20 条 | 4 个字 |
  | **适中**（默认） | 40 条 | 2 个字 |
  | 密集 | 80 条 | 1 个字 |

  适中取 40 条：半屏 7 条轨道、每条约 4 条可见，大约 28 条。40 给顶部 / 底部弹幕和全屏留出余量。
- **屏蔽**：滚动 / 顶部 / 底部 / 彩色（颜色不是白色的），可多选。改了之后，屏幕上属于这一类的弹幕立刻去掉，不做淡出。
- **暂停**：所有弹幕原地停住。
- **拖进度**：拖动时隐藏弹幕，松手后从新时间点重新排。不回填松手前几秒的弹幕。
- **倍速**：按片子的时间出现，横穿还是 8 s 实际时间。超出密度的直接丢掉。
- **两侧羽化**：画面左右各 1.5°，是层的属性，不是逐条做动画。作用是减少浮在前面的字被画框切断的感觉，也就是窗口冲突。

**分层漂浮**

画稿：「漂浮感」。

弹幕不贴在画面上，而是浮在画面前面。它们分成远、中、近三层，层与层之间有一点纵深，「浮」的感觉就从这里来。深度用**视差 φ** 来记，也就是相对画面平面的交叉视差，单位是度：同样的 φ 在任何距离下浮起来的感觉一样。

距离和视差的换算是 d = 1 ÷ (φ ÷ IPD + 1 ÷ D)。其中 D 是屏幕距离，瞳距 IPD 按 63 mm 算。

| φ | D = 2 m 时在画面前 | D = 3 m | D = 5 m |
|---|---|---|---|
| 0.10° | 11 cm | 23 cm | 61 cm |
| 0.25° | 24 cm | 52 cm | 129 cm |
| 0.40° | 36 cm | 75 cm | 178 cm |
| 0.60° | — | 100 cm | 227 cm |
| 1.00° | — | 136 cm | 290 cm |
| 上限 | 0.45° → 1.60 m | 1.0° → 1.64 m | 1.0° → 2.10 m |

- **远层**：
  - 「自动」开（默认）：φ = 内容 + 0.10° + k × 0.05°，k = −2…+6，**默认 0**。
  - 「自动」关：φ = k × 0.05°，k = 0…12，即 0–0.60°，0 = 贴屏。
- **中层** = 远层 + Δ/2；**近层** = 远层 + Δ。
- **层次** Δ 是三层的总跨度：关 0 / 浅 0.15° / **中 0.30°** / 深 0.45°。
- 轨道按 **远、中、近、中** 循环分配，同一条轨道永远在同一层。所以相邻两行只差 Δ/2，默认 0.15°。
- 顶部、底部弹幕在近层；**字幕在远层**。
- **「内容」的取法**：
  - 取深度图在弹幕显示区域里的第 98 百分位视差。
  - 往前立刻跟；往后每秒最多退 0.05°。
  - 3D 关闭时为 0。原生 3D 片源没有深度图，按 0.25°。
- **上限**：近层 φ ≤ **1.0°**，并且距眼 ≥ **1.6 m**，永远在控制条（1.4 m）后面。超过时先压缩 Δ，还不够再压远层。
- 例：3 m、3D 标准、自动 +0、层次中。画面最靠前的内容在 2.57 m（0.2°），这时：
  - 远层 2.40 m（0.30°），在画面前 60 cm；
  - 中层 2.18 m；
  - 近层 2.00 m（0.60°），在画面前 1 m；
  - 控制条在 1.4 m。

为什么不晕：

1. **每条弹幕从出现到离开深度不变。** 层的深度在它出现那一刻定下，眼睛横着追字时不用改聚散。「内容」的变化只影响之后出现的弹幕。
2. 按轨道分层，同一行永远同一层；相邻两行只差 0.15°。
3. 总范围在 1° 以内，最近不近于 1.6 m，永远在控制条后面。
4. 「自动」时整叠弹幕都在画面最靠前的内容前面，不会出现「被挡住的字反而更近」。
5. 两侧羽化，减少窗口冲突。
6. 深度只靠视差，不做近大远小、近快远慢、近亮远暗。所有层同速，不违反 §5.6 不做视差动画的规定。
7. 只有自己拖「漂浮感」或「层次」时，屏幕上已有的弹幕和字幕才一起移到新深度（200 ms）。

**开关**

有三个地方，都改同一个值（全局）：

- 控制条上的「弹」：B 站用户的习惯，一键开关。
- Y 键：不用找界面就能开关，出提示「弹幕 已关」或「弹幕 已开」。
- 调色板弹幕页第一行。

**渲染**

- **图集**：一张 2048 × 2048 的图集。
  - 每条弹幕在**出现前**画一次：文字、字号、描边、合并后的「×N」都烘进去。之后**不再改**，离开画面后释放。
  - 颜色在每帧合成时按条乘上，所以图集只存字形和描边两个通道。
  - 图集满了，新弹幕按「没有空轨道」处理。
- **每眼一层**：每帧把活着的弹幕按位置画进左右眼各一张贴图，一次 instanced draw。
  - 左眼贴图里每条右移 φ/2，右眼左移 φ/2。按 40 texel/° 算，0.60° 是每眼 12 texel。
  - 两张贴图和画面同轴、同角宽；层的几何位置就在画面上，浮起来全靠视差。
  - 贴图宽最多 2048。巨幕 80° 时约 25.6 texel/°，仍高于有效 PPD。
  - 高度只覆盖所选区域：半屏时只有一半。
- 屏幕上一条弹幕都没有时，两层都不提交。

**手势**

和手柄完全一样，只是开关少了 Y 键（「弹」或调色板）。

### 6.11 字幕

画稿：「静态字幕」。

字幕在这一版降为次要：样式和位置照常可调，深度不单独设，和弹幕共用「漂浮感」。

| 量 | 值 |
|---|---|
| 字体 | 思源黑体（Noto Sans CJK SC）500，`#F3F3F1`。描边 0.06 em `#0E0F12` 85%，加阴影 |
| 字号 | 小 1.3° / **中 1.6°** / 大 2.0°。最小 1.2°，即 VR 最小字 1.1° 再加 10%，因为背景在动 |
| 行 | 最多 2 行，片源本来是 3 行就 3 行。每行 ≤ 16 个汉字或 42 个拉丁字母，行高 1.3。在标点处断成两行差不多长 |
| 位置 | 画面下沿上方 1–12°，每格 0.5°，**默认 2°**。不低于平视以下 16° |
| 背景 | **无底**（默认）/ 半透明底（`#0E0F12` 64%，逐行一块底） |
| 深度 | 在**远层**，也就是漂浮感那一层。字幕按自己的字幕框测画面深度：每条字幕取开头 3 帧的中位数，显示期间只往前、不往后 |
| 曲度 | 跟随屏幕（默认）/ 平 / 自定义，在设置里改（§6.12） |
| 和弹幕的关系 | 滚动弹幕不进字幕区；底部弹幕排在字幕上面 |
| 避让 | 钉住的调色板或弹出卡片挡住字幕时，字幕抬到它上沿以上 1°（滞回 1°，200 ms）。手上的调色板不推字幕 |
| 图形字幕（PGS 等） | 只能缩放（70–150%）和挪位置；背景变灰。漂浮感和曲度照常 |
| 贴图 | 1 层，左右眼共用，1440 × 400。只在换字幕或改样式时重画；没有字幕时不提交 |

### 6.12 屏幕操控

画稿：「调整屏幕」「按键判定」「弹幕曲面」，以及调色板屏幕页。

**三个量**

| 量 | 范围 | 档位 | 说明 |
|---|---|---|---|
| 大小 | 30–90°（水平视角） | 小 40° / **中 50°** / 大 62° / 巨幕 80° | 按角度定。改大小不改距离 |
| 距离 | 2–8 m，对数刻度 | 2 / **3** / 5 m | 只改立体纵深，画面看起来一样大，英寸数跟着变。最近 2 m，再近就和弹幕、控制条挤在一起 |
| 曲度 | 0–100%，每格 5%，出厂 **0%** | — | 半径 R = 距离 ÷ c，角宽度不变。c = 0 是平面 quad；100% 时半径等于观看距离，画面每一点离眼睛一样远 |

**英寸**：按 16:9 的对角线算。宽 = 2 × 距离 × tan(大小 / 2)，对角线 = 宽 ÷ 0.8716。例：

- 50° @ 3 m = 126 寸；
- 50° @ 3.4 m = 143 寸；
- 62° @ 3 m = 163 寸。

**扳机按住 + 摇杆**

判定见 §6.4。

- **方向**：
  - 摇杆前后 = 远近，向前 = 推远，像把屏幕推出去。
  - 左右 = 大小，向右 = 变大。
- **速度**：和推的深浅成正比。满推时大小 20°/s；距离每秒 ×1.6，从 2 m 到 8 m 约 3 s。
- **档位**：
  - 经过档位时停 300 ms，加 15 ms / 0.5 的振动。
  - 松开时，如果离档位在 ±1.5°（大小）或 ±4%（距离）以内，就吸上去。
- **读数**：
  - 在提示槽位里，24° × 2.8°，贴图 960 × 112，数字变了才重画。
  - 调距离时显示「↕ 3.4 m · 中 50° · 143 寸」，下面带 2 / 3 / 5 的刻度；调大小时显示「↔ 大 62° · 3.0 m · 163 寸」。
  - 只显示正在调的那根轴，另一根轴的值放在后面做参照。
- **松开扳机 = 保存**：存为全局值，和设置页是同一个值。不暂停。
- **按 B = 撤销**：回到按下扳机前的大小和距离。
- 握把按住 + 摇杆完全一样。握把按住 + 移动手柄照旧是拖动位置。
- 调整中：控制条和提示隐藏；调色板开着时降到 40%。

**曲度**

- **画面**：平面是 quad 层，曲面是柱面层（`XR_KHR_composition_layer_cylinder`），**同一个角宽**。
- **弹幕和字幕的曲度**：
  - **跟随屏幕**（默认）：和画面**同轴**。弹幕沿弧线从右缘绕到左缘，角速度不变。
  - **平**：放在画面两边缘连成的**弦**上。曲面的两边比中间近，平面放在弦上才不会跑到画面后面。
  - **自定义**：0–100%。
  - 不管哪种，弹幕面和画面相切在中心或两边缘，取靠前的那个，**永远不在画面后面**。
- **不能用时**（§6.3）：
  - 影院房间里屏幕永远是平的，曲度行变灰，记住的值不丢。
  - 头显不支持柱面层时，曲度行和设置里的两个曲度都变灰，并写原因。
- **影院房间为什么永远是平的**：房间模型里的银幕是平的，曲面画面会和房间的透视打架。

**位置**

- 握把按住 + 移动手柄：拖动画面，在以人为中心的球面上移动，距离不变。
- 长按 PICO 键：系统重新居中，画面回到正前方。

## 7 Compose 落地说明

- **画布与密度**：设计按 1280×720 画。要先确认 PICO 2D 窗口里 **1 px 是否等于 1 dp**（窗口的 density）。如果不是，所有 token 按 dp 统一换算，比例不变。
- **悬停**：PICO 把射线投到 2D 窗口时，应该会发 `ACTION_HOVER_ENTER / MOVE / EXIT`。用 `Modifier.hoverable(interactionSource)` 加 `interactionSource.collectIsHoveredAsState()` 驱动放大和底色。**要在头显上确认确实收得到 hover 事件**。
- **放大用 `graphicsLayer { scaleX; scaleY }`**，不改 layout 尺寸，这样邻居不会被挤动，也不会触发重新布局。
- **关掉默认的 ripple**（`indication = null`，自己画按下态）：水波纹在低 PPD 下只是一团白光，而且和悬停放大重复。
- **滞回**：在命中框外扩 8 px 的 `pointerInput` 里判定离开，或者给 hover 加 80 ms 的离开延迟，二选一，在头显上比较效果。
- **骨架延迟**：用 `LaunchedEffect` 等 300 ms，数据还没到才显示骨架。
- **列表**：海报行用 `LazyRow`，配合 `snapFlingBehavior` 吸附到卡片边缘；分类网格用 `LazyVerticalGrid(GridCells.Fixed(6))`。
- **字体**：系统 Noto Sans CJK，只用 400 / 500 / 600 三个字重。数字开 `fontFeatureSettings = "tnum"`。
- **VR 场景内的贴图**：和现在的 TransportBar 一样，用 Android Canvas 画进一张 bitmap 再上传。只在状态变化时重画（悬停目标变化、播放和暂停切换、每秒的时间）。命中测试在贴图坐标里做，各控件的矩形和画图共用同一份常量。
- **调色板**：
  - 同样是一张 1024 × 768 的 Canvas bitmap。只在悬停的行、值、标签或页变了时重画；连续改值时每秒最多 8 次，跟着摇杆连续改值的节奏。
  - 位置每帧按握把姿态更新。眼睛方向修正走 100 ms 低通。
  - 调整屏幕时降到 40%：
    - 优先用 `XR_KHR_composition_layer_color_scale_bias` 改层的 alpha；
    - 没有这个扩展就重画一次半透明版本。
  - 行、复位钮和标签的矩形，和画图共用同一份常量。
- **弹幕**：
  - 图集 2048 × 2048，两个通道（字形、描边）。每条弹幕出现前用 `StaticLayout` 画进一个空位，只上传那一块（`glTexSubImage2D`），之后不再改。
  - 每帧用一次 instanced draw 把活着的弹幕画进左右眼两张 swapchain 贴图。两层的 `eyeVisibility` 分别是 LEFT / RIGHT。
  - 羽化和整体不透明度在这个 shader 里乘。
  - 曲面时两层是和画面同轴的柱面层。
  - 轨道分配、等待、丢弃和合并都在 CPU 上做，只在新弹幕到来时计算。
- **深度读回**：
  - 漂浮感的「内容」= 深度图在弹幕区域（字幕用字幕框）里的第 98 百分位视差。
  - 在 GPU 上做 64 格直方图，用 PBO 异步读回几十个字节，每秒 10 次。晚 1–2 帧没关系，因为只影响之后出现的弹幕。
  - 往前立刻跟，往后每秒最多退 0.05°。
- **柱面层**：
  - 启动时查 `XR_KHR_composition_layer_cylinder`，现有代码里是 `ctx->cylinderSupported`。没有就把三个曲度都锁成平面，并在调色板和设置里写原因。
  - 影院房间里强制平面。
- **扳机与摇杆的判定**：写成一个状态机，放在一处。350 ms、死区 0.25、阈值 0.5、300 ms 档位停留这些数都是常量，方便在头显上调（§8）。
